# iPhoneのホーム画面アプリとScriptableウィジェット

[画面付きの設定手順](../widget-setup.html)をiPhoneのSafariで開いてください。ウィジェット用スクリプトとサーバー側の受信処理は作成済みです。iPhoneへのScriptableインストール、キーの入力、ホーム画面への追加だけは端末上で行います。

## ホーム画面アプリ

SafariでHubを開き、共有 → ホーム画面に追加。Webアプリとして開く設定がある場合はオンにします。専用アイコンを用意しています。App Store向けのネイティブアプリではなく、現在のHubをアプリ形式で開くものです。Safariとは別にログインが必要な場合があります。

## ウィジェット

1. App StoreからScriptableをインストール。
2. 設定ページの「スクリプトをコピー」を押す。
3. Scriptableで「＋」から新しいスクリプトを作り、コードを貼り付け、「Family Hub」として保存。
4. Hubの「＋ 追加」→「iPhoneウィジェット」→「ウィジェット用キーを設定する」からキーを発行し、コピー。
5. Scriptableで「Family Hub」を実行。初回入力欄に、今発行したウィジェット専用キーを貼り付けて接続。
6. iPhoneのホーム画面を長押し → 編集 → ウィジェットを追加 → Scriptable → 中サイズを追加。
7. ウィジェットを長押し → ウィジェットを編集 → Scriptに「Family Hub」を選ぶ。

Apple同期キーやOpenAI APIキーは使いません。パスワードもスクリプトに書きません。専用キーはScriptableのKeychainへ保存されます。スクリプトファイルにキーを埋め込んだり、ウィジェットのParameterにキーを設定したりする必要はありません。

## 表示内容

- 日本時間の今日の予定（終日を先に、時刻順）
- 未完了タスク数
- 未完了の買い物件数
- Hubの取得時刻

Hubに直接登録したものと、既存のApple同期の受信済みデータを合算します。元のHubと同じアカウントの情報だけです。同期元で完了・変更したものは、同期ショートカット実行後に取り込まれます。

小・中・大サイズに対応します。小サイズでは予定を1件、中は3件、大は7件まで表示し、残りは件数で案内します。タップするとSafariなどでHubの予定タブを開きます。ウィジェットからの完了・編集操作はありません。

## 更新、オフライン、解除

更新間隔はiOSが決めます。15分後からの更新を依頼しますが、即時更新や定刻更新は保証されません。Scriptableで実行すると手動確認できます。

通信できない場合は同じ日の6時間以内の保存分を「保存分」と明記します。前日のデータを今日として表示しません。期限切れ・無効キーの応答を受けたらKeychain設定と保存分を削除し、再設定を案内します。iOS上の古い表示は次回のウィジェット更新まで残る場合があります。

キーの有効期間は90日。Hub側の「無効にする」で以後の取得を止められます。再発行は既存のウィジェット用キーを無効にするため、複数の端末で使っている場合はそれぞれ再設定します。Apple同期用キーには影響しません。Hubからのログアウトだけではウィジェット用キーは解除されません。

Scriptable内でこのスクリプトを実行すると、プレビュー・キー再設定・Hubを開く・端末の保存設定の削除を選べます。端末の設定削除と、サーバー側でのキー無効化は別です。

## 実装と検証

- `widgets/Family-Hub.js`：iPhoneのScriptableで実行するスクリプト。
- `widget-settings.js`：ログイン済みHubからの専用キー発行・無効化。
- `supabase/functions/widget-summary`：専用キーをSHA-256化し、サーバー専用RPCを通じて集計結果を取得。
- `widget_devices`：キーのハッシュと期限だけを保持。RLSで本人のキーだけ管理できる。
- `get_widget_summary(text)`：SECURITY INVOKER。service_role以外には実行権限なし。対象アカウントはキーのDB照合から決め、URLのowner_idなどは受け付けない。

本番DB上で一時的な検証データを使い、当日抽出・合算・別アカウントの分離・期限切れ・RLSを検証し、検証データはすべてロールバックしました。ScriptableのAPIを模擬した表示・保存分・失効時処理のテストも行っています。iPhone実機でのScriptable描画とiOSの更新頻度は、この環境では検証できないため、初回設定時に確認してください。
