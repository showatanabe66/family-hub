# お出かけホーム（Muse仕様の組み込み）

既存のログイン・AIネット検索・候補登録・iPhoneウィジェット・アルバムを維持し、お出かけタブに日付選択、天気の総評、上位3件、番号付き地図、条件別一覧を追加しました。

## データの追加・修正

`data/outing-spots.json` の配列を編集します。初期31件の名称・分類・ふれあい・移動時間は、提供されたMuse仕様書に基づきます。移動時間は実測値ではありません。確認できた公式アクセスページから地図の座標を読み取りました。位置未確認の施設は `latitude` / `longitude` が null で、地図や現地予報に架空の位置を使用しません。

IDを変更すると、そのスポットの端末内マークやアルバムとの対応が変わります。`id` は固定してください。既存の登録済み施設と名称が一致すると既存のID・保存済みマークを優先して統合します。公式名称の空白・全角半角の差は吸収します。別名の場合は別スポットとして扱います。

追加できる項目：`address`, `latitude`, `longitude`, `highlight`, `hoursSat`, `hoursSun`, `priceLevel`, `rating`, `ratingCount`, `website`, `photo: {url, credit}`。未確認の値は null。写真は使用許諾とクレジットを確認したHTTPS画像のみ設定してください。写真がない場合は装飾イラストを表示します（施設の実写写真ではありません）。口コミ・料金は生成しません。営業時間は曜日別の値が設定された場合に表示します。

## 並び替え

`outing-model.js` に純粋関数として実装。晴れ：屋外40・両方25・屋内10、曇り：25・25・15、雨：-10・20・40。雨は降水確率40%以上または天気コード45以上。雨の屋外には降水確率÷10を追加減点。20分以内+10、30分以内+5、評価×2、屋外で風速30km/h以上-5。理由は最大3件で強風の注意を優先。訪問済みは減点せず、必要なら「行った場所を隠す」で除外します。

現地予報を優先し、取得できない施設は東戸塚の予報を参考にすることを明示します。全予報がない場合は距離・確認済み評価を基に代替表示します。天気との相性は営業中・年齢条件の確認を意味しません。営業・年齢・車のルートまで検索確認したい場合は既存のAIネット検索を実行してください。

## 天気と地図

`outing-forecast.js` にOpen-Meteoクライアントを分離。東戸塚＋座標確認済み施設を最大12地点ずつまとめて取得し、16日間の日別予報を位置別に30分キャッシュします。メモリとlocalStorageに公開予報のみ保存し、日付変更時に該当日を選択します。再取得ボタンでキャッシュを更新。タイムアウト・APIエラー・予報対象外は「未取得」を表示します。日付は日本時間の当日〜16日先。Open-Meteoの16日間は通常当日〜15日先のため、16日先は天気なしで閲覧できます。既存AIの範囲は当日〜15日先のままです。日付変更ではOpenAI APIを呼びません。

Leaflet 1.9.4（BSD-2-Clause）を `vendor/` に同梱。地図表示ボタンを押したときだけOpenStreetMapの標準タイルを読み込み、帰属を表示。タイルの事前取得やオフライン保存はしません。番号は絞り込み後の一覧に対応し、ピン選択でカードへ移動します。

## 保存とアルバム

初期スポットのfavorite/visitedは `outing-catalog-marks-v1:<user-id>` に端末内保存。既存Supabase登録候補のマークは従来どおりSupabaseへ保存します。ログアウト・アカウント切替で前ユーザーの表示を消去します。初期スポットも既存のアルバムブリッジを通じて共通のスポットIDで記録でき、写真記録がある場合は自動で訪問済みになります。アルバムの写真・記録は同じアカウントの端末に同期します。以前の端末内アルバムは移行ボタンで同期できます（詳細は `weekend-album.md`）。

## 検証

Nodeテスト：晴れ/雨の順位、点数、強風理由、3件上限、現地予報優先、訪問を残すこと、既存候補の統合、ゼロ降水確率、キャッシュ、取得失敗、範囲外、既存フィルター/アルバム/ウィジェット/SW。

Playwright：31件と上位3件、日付変更で晴れ→雨と屋内優先、ふれあい5件、マークの再読込後保持、未訪問の絞り込み、地図ピンとカード連携、既存アルバムタブ、320/390/430/1024pxの横はみ出し確認。通信は模擬予報と模擬ログインに置換し、有料AIを実行していません。
